# 📚 CBC-MASTER

### All-in-One Kenyan CBC Teacher Productivity Toolkit for Grades 1–12

**CBC MASTER by Joseph Mbui** is a modern, mobile-first Progressive Web App (PWA) designed to help Kenyan teachers manage everyday CBC teaching, planning, assessment, and reporting tasks from one workspace.

> **Plan. Teach. Assess. Report. — All in one workspace.**

---

## 🚀 Vision

CBC MASTER aims to make lesson preparation, assessment, reporting, and curriculum planning easier by giving teachers one practical digital workspace.

Instead of using multiple disconnected tools, teachers can access essential teaching tools from one application.

---

## ✨ Core Features

### 📊 Report Books

- Create student report records
- Manage student performance
- Enter subject results
- Calculate totals and averages
- Generate performance summaries
- Add teacher comments
- Save reports locally
- Prepare reports for printing and PDF generation

### 📚 Schemes of Work

- Create curriculum schemes
- Organize work by grade
- Organize content by term
- Record weeks and lessons
- Store teaching resources
- Save and manage schemes

### 📝 Lesson Plans

- Create daily lesson plans
- Select grade and subject
- Define learning objectives
- Add activities and resources
- Record assessment methods
- Add teacher reflections
- Save lesson plans for future use

### 🎯 Assessment Rubrics

- Create assessment criteria
- Define performance levels
- Record learner achievement
- Build reusable rubrics
- Save assessment templates

### 👨‍🎓 Students

- Add students
- Edit student information
- Organize learners by grade/class
- Search and filter students
- View student records
- Connect students with report books

### 📁 Saved Documents

- View saved teaching documents
- Manage generated content
- Organize documents
- Search documents
- Edit or delete documents
- Print or export documents

### 👤 Teacher Profile

- Store teacher information
- Set current teaching grade
- Personalize the workspace
- Manage teacher preferences

### 📈 Insights

- Student statistics
- Report statistics
- Document statistics
- Workspace overview
- Performance summaries

## 🧱 Technology Stack

CBC MASTER is built using lightweight web technologies:

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Progressive Web App (PWA)
- Service Worker
- Web App Manifest

The application is intentionally built without a heavy frontend framework, making it lightweight, responsive, and easy to deploy.

---

## 📱 Mobile-First Design

CBC MASTER is designed primarily for mobile devices.

The interface includes:

- Responsive layouts
- Mobile navigation
- Bottom navigation
- Slide-out sidebar
- Touch-friendly controls
- Safe-area support
- Offline-ready architecture
- Responsive desktop layout

---

## 💾 Local Data

The current application uses browser `localStorage` for local workspace data.

Example storage areas include:

```text
cbc_teacher
cbc_current_grade
cbc_students
cbc_reports
cbc_documents
This allows the core workspace to operate without requiring a server or database.
Future versions may introduce secure cloud synchronization and account-based services.
📴 PWA Support
CBC MASTER includes Progressive Web App functionality through:
manifest.json
service-worker.js
The PWA architecture is designed to support:
Installation on supported devices
Offline access
Cached application resources
Mobile-app-like experience
Future background capabilities

🇰🇪 Built for Kenyan CBC
CBC MASTER is designed with the Kenyan Competency-Based Curriculum environment in mind, supporting Grades 1–12 and teacher-focused planning, assessment, and reporting workflows.
The application is intended as a productivity tool and should be used alongside official curriculum materials, school policies, and institutional requirements.
🔐 Privacy
The current version stores workspace information locally in the user's browser.
No account or cloud database is required for the core local functionality.
Future versions may introduce secure cloud synchronization, authentication, backups, and account-based services.
💡 Project Goal
The goal is simple:
Give teachers one workspace for planning, teaching, assessing, and reporting.
CBC MASTER is being developed incrementally, with each major module becoming functional before moving to the next.
